# Project-local 3D models

The XT30 models in `Connector_AMASS.3dshapes` are derived from
[`zhbi98/kicad-libs`](https://github.com/zhbi98/kicad-libs) at commit
[`148532da33e96d51dd45b4d82f271bfc2cb3ff77`](https://github.com/zhbi98/kicad-libs/tree/148532da33e96d51dd45b4d82f271bfc2cb3ff77).

Source files:

- `3dmodels/3rd_Connector_AMASS_TH.3dshapes/AMASS-TH_1x2P-P3.5-V_XT30PW-M.step`
- `3dmodels/3rd_Connector_AMASS_TH.3dshapes/AMASS-TH_1x2P-P3.5_XT30PW-F-1.step`

The source STEP geometry and colors are preserved. The files were renamed to
match KiCad's corresponding model references. The project-local footprints in
`Project_Connector_AMASS.pretty` provide the model paths and offsets needed to
align their original origins with the KiCad footprints.
